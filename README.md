# درسیار (DarsYar) — پلتفرم جامع مدیریت مدرسه و آموزش هوشمند

**درسیار (DarsYar)** یک سامانه کامل، ماژولار و دوزبانه برای مدیریت مدرسه، آموزش آنلاین و ارتباط شفاف بین کادر آموزشی، دانش‌آموزان و خانواده‌ها است. این پلتفرم با **PHP 8.2+** و **MySQL / MariaDB** پیاده‌سازی شده و بدون نیاز به Node.js یا Docker، برای اجرای محلی روی **XAMPP** و استقرار مستقیم روی هاست اشتراکی **cPanel** آماده است.

---

## ویژگی‌های کلیدی

### ۱. هفت پنل مستقل مبتنی بر نقش (`RBAC` + ضد `IDOR`)
- **مدیر کل سامانه (`super_admin`)**: داشبورد کلان، مدیریت مدارس (`schools`)، مدیریت مدیران، سیستم مدیریت محتوای وب‌سایت عمومی (اخبار، بنرها، فعالیت‌ها، گالری و رویدادها)، اطلاعیه‌ها، تنظیمات سراسری زبان و پوسته و اسکای‌روم همراه با تست زنده اتصال، گزارش ممیزی (`audit_logs`) و پایش سلامت سیستم.
- **مدیر مدرسه (`director`)**: نظارت بر معاونین، رتبه‌بندی قابل تنظیم معلمان و دانش‌آموزان، مقایسه عملکرد کلاس‌ها، گزارش‌های تحلیلی با خروجی CSV، اطلاعیه‌ها و برنامه‌های هفتگی.
- **معاون آموزشی (`vice_principal`)**: مدیریت سال تحصیلی، نیم‌سال، پایه‌ها، کلاس‌ها، دروس و انتساب معلمان، ثبت و درون‌ریزی دسته‌ای دانش‌آموزان با CSV، **تولید خودکار دسته‌ای حساب اولیا** (نام کاربری یکتا، رمز عبور موقت، جلوگیری از حساب تکراری، پیوند چندفرزندی، خروجی چاپی و CSV و اجبار تغییر رمز در اولین ورود)، حضور و غیاب مدرسه‌ای و صدور/ثبت نظر کارنامه.
- **مشاور تحصیلی (`counselor`)**: مدیریت دانش‌آموزان تحت پوشش، پاسخ به درخواست‌های برنامه مطالعاتی، تدوین برنامه مطالعاتی هفتگی و تکالیف روزانه، یادداشت‌های مشاوره‌ای (با قابلیت اشتراک‌گذاری با اولیا) و تحلیل پیشرفت دانش‌آموز.
- **دبیر (`teacher`)**: کلاس‌های درس واگذارشده، بانک سوال، آزمون‌های آنلاین (بازه زمانی سرور-محور، محدودیت زمان، تصادفی‌سازی، نمره منفی، تصحیح خودکار تستی و دستی تشریحی)، آزمون‌های حضوری + درون‌ریزی نمرات CSV، آزمونک‌های تمرینی روزانه، تکالیف و بازخورد، کلاس‌های آنلاین اسکای‌روم، حضور و غیاب کلاسی و گروه‌های گفت‌وگوی درسی.
- **دانش‌آموز (`student`)**: داشبورد شخصی، برنامه هفتگی و دروس، شرکت در آزمون‌های آنلاین و مرور پاسخ‌ها، آزمونک‌های روزانه با نمودار پیشرفت، بارگذاری تکالیف و دریافت بازخورد، چک‌لیست تعاملی برنامه مطالعاتی با ثبت AJAX و ثبت درخواست برنامه، کلاس‌های اسکای‌روم، گفت‌وگوی درسی، اعلان‌ها و کارنامه قابل چاپ.
- **ولی / خانواده (`parent`)**: تغییر سریع بین فرزندان پیوندشده با کنترل دسترسی سخت‌گیرانه (`parent_student`)، خلاصه حضور و غیاب، نتایج آزمون‌ها و آزمونک‌ها، وضعیت تکالیف و بازخورد دبیر، پیشرفت برنامه مطالعاتی، یادداشت‌های مشاور، برنامه هفتگی و کارنامه قابل چاپ.

### ۲. سیاست دو‌زبانه، تقویم جلالی و سیستم طراحی اختصاصی
- **فقط ۲ زبان رسمی**: **فارسی (`fa`)** به عنوان زبان اول و پیش‌فرض با چیدمان راست‌به‌چپ (`RTL`)، تقویم جلالی و ارقام فارسی + **انگلیسی (`en`)** با چیدمان چپ‌به‌راست (`LTR`) و تقویم میلادی؛ زبان عربی به طور کامل حذف شده است.
- **تضمین هماهنگی ترجمه‌ها**: تمام `۷۰۲` کلید ترجمه در [`lang/fa.php`](lang/fa.php) و [`lang/en.php`](lang/en.php) از طریق [`Translator::checkConsistency()`](app/Core/Translator.php) دارای برابری صددرصدی هستند.
- **سیستم طراحی اختصاصی درسیار ([`DESIGN.md`](DESIGN.md))**: طراحی مینیمال و لمسی با خطوط `1.5px`، سایه‌های سخت هندسی، پالت اختصاصی لاجوردی درسیار (`#2554FF`) و کاغذ کرم (`#FAF9F5`) / تم تیره (`#0B0F17`)، فونت‌های محلی `Vazirmatn` و `Inter`، آیکون‌های برداری Lucide و صفحه انیمیشنی ورود و ثبت‌نام (`/login` و `/register`).

## پشته فناوری

| بخش | فناوری |
| :--- | :--- |
| **سمت سرور (Backend)** | PHP `8.2+`، معماری ماژولار MVC + لایه سرویس، PSR-4، PDO با Prepared Statements |
| **پایگاه داده** | MySQL `8+` / MariaDB `10.4+` (`۸` فایل مایگریشن، `۵۵` جدول) + پشتیبانی SQLite برای تست خودکار |
| **سمت کاربر (Frontend)** | HTML5، CSS3 با متغیرهای طراحی و Logical Properties، JavaScript خالص + Fetch API و نمودارهای SVG |
| **امنیت** | هش رمز Argon2id / bcrypt، توکن CSRF، Rate Limiter ورود، Anti-IDOR در پنل‌ها و دانلود فایل، اعتبارسنجی MIME/پسوند آپلودها |
| **میزبانی** | XAMPP محلی (`START_DARSYAR.bat`) و هاست اشتراکی استاندارد cPanel با قوانین `.htaccess` |

## راه‌اندازی محلی (XAMPP / Windows)

</div>

```bash
# ۱. کپی فایل تنظیمات محیطی و وارد کردن مشخصات دیتابیس
copy .env.example .env

# ۲. اجرای مایگریشن‌های دیتابیس (غیرویرانگر)
php bin/migrate.php

# ۳. درج ساختار پایه و حساب‌های نمونه محیط توسعه
php bin/seed.php

# ۴. اجرای خودکار سرور محلی با اسکریپت ویندوز:
START_DARSYAR.bat
```

<div dir="rtl">

یا با دستور مستقیم PHP و باز کردن نشانی `http://127.0.0.1:8000/login` (یا `http://127.0.0.1:8000/register`):

</div>

```bash
php -S 127.0.0.1:8000 -t public
```

<div dir="rtl">

برای متوقف کردن سرور محلی PHP بدون بستن سرویس‌های اشتراکی MySQL/Apache از `STOP_DARSYAR.bat` استفاده کنید.

> حساب‌های آزمایشی توسعه صرفاً زمانی که `APP_ENV=local` باشد در کشوی بازشونده صفحه ورود نمایش داده می‌شوند و در محیط تولید (`production`) مخفی هستند.
