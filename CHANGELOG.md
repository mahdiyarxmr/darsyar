# Changelog — DarsYar (درسیار)

## [2.0.0] - DarsYar Full Platform Rebuild & Design System Implementation
- **Identity & Two-Language Policy**: Rebranded platform cleanly to **DarsYar (درسیار)**; removed all Arabic (`ar`) locale files, routes, selectors, and references. Strictly standardized on **Persian (`fa`, primary/default RTL, Jalali dates, Persian digits)** and **English (`en`, secondary LTR, Gregorian dates)** with route-preserving language switching and automated `Translator::checkConsistency()` parity check (`681` keys).
- **UI/UX Design System (`DESIGN.md`)**: Rebuilt all layouts, partials, public pages, and 7 panel interfaces according to [`DESIGN.md`](DESIGN.md) using CSS custom properties, local `Vazirmatn` & `Inter` webfonts (`public/assets/fonts/`), custom SVG emblem (`logo.svg`), inline Lucide SVG icons (`App\Core\Icon`), reusable UI helpers (`App\Core\Ui`), responsive mobile drawer, charts, modals, confirmation dialogs, skeletons, and Light/Dark themes.
- **Database Migrations `007` & `008`**: Added `study_plan_requests` (formalizing DDL for fresh SQLite/MySQL installs), `schools`, `counselor_assignments`, and `counseling_notes` (bringing schema to 55 tables), exported updated `database/schema_mysql.sql`, and implemented non-destructive idempotent seeding (`SCH-001`, multi-child parent linkage, counselor assignments/notes, sample sessions & discussions).
- **Controller & Security Upgrades**: Added multi-school CRUD & health diagnostics (`SuperAdminController`), live Skyroom diagnostic (`SkyroomService::testConnection()`), Director vice-principal toggle + CSV reports + announcements, Vice Principal semesters + staff toggle + student search/reassignment + monthly attendance summary + report card comments, Counselor caseload assignment + study plan request fulfillment + notes + student analysis, Teacher classes + classroom status + attendance history, and anti-IDOR hardening in `ReportCardController::downloadFile()`.
- **Local XAMPP Launchers & Verification**: Added `START_DARSYAR.bat` and `STOP_DARSYAR.bat`; verified 146 PHP files (`0` syntax errors), `55` unit/integration tests passing (`bin/test.php`), and `123` live HTTP E2E assertions passing across all 7 panels.
